The Regression Estimator

Sampling Theory · Course 206

The ratio estimator assumes a line through the origin. What if the true line has an intercept? Here we slide the sample mean along a fitted line to a known population mean, and see why that is the best linear correction.

See it first

Ten stores (last year's sales \(x\), this year's \(y\)). We know the population mean of last year's sales, \(\Xb\). Move \(\Xb\) and watch the regression estimate slide along the line while the plain sample mean stays put.

Gold-ish dot: \((\bar x,\bar y)\). Vertical line: \(\bar X\). Filled square: the regression estimate (the line's height at \(\bar X\)). Dashed line: the fixed-slope version.

Why go beyond the ratio estimator?

1. Ratio's limit

\(\hat{\bar Y}_R=\bar y\,\Xb/\xb\) is the sample mean scaled up or down. It is built for \(Y\approx RX\), a line through the origin.

2. Real data

Usually \(Y_i\approx\alpha+\beta X_i\) with \(\alpha\ne0\). Forcing the line through zero wastes precision.

3. The idea

Correct \(\bar y\) by the gap \(\Xb-\xb\), using a weight chosen to minimise variance. Requirement: \(\Xb\) must be known.

Notation (SRSWOR, \(f=n/N\))

\[S_{XY}=\frac{1}{N-1}\sum(X_i-\Xb)(Y_i-\Yb),\quad \rho=\frac{S_{XY}}{S_XS_Y},\quad \beta=\frac{S_{XY}}{S_X^2}=\rho\frac{S_Y}{S_X}\]

Sample versions: \(s_{xx}=\sum(x_i-\xb)^2\), \(s_{xy}=\sum(x_i-\xb)(y_i-\yb)\), \(s_{yy}=\sum(y_i-\yb)^2\). Four facts from simple random sampling are all we need:

\[E(\yb)=\Yb,\ \ E(\xb)=\Xb,\ \ \V(\yb)=\tfrac{1-f}{n}S_Y^2,\ \ \V(\xb)=\tfrac{1-f}{n}S_X^2,\ \ \Cv(\xb,\yb)=\tfrac{1-f}{n}S_{XY}\]

Everything below is algebra on these five lines.

The difference estimator

Definition and unbiasedness

Pick any constant \(\phi\) and adjust the sample mean by the miss in \(\xb\):

\[\hat{\bar Y}^{*}=\yb+\phi(\Xb-\xb)\]

Take expectations; \(E(\xb)=\Xb\) kills the correction.

\[E(\hat{\bar Y}^{*})=E(\yb)+\phi\big(\Xb-E(\xb)\big)=\Yb+\phi(\Xb-\Xb)=\Yb\]

So it is unbiased for every \(\phi\). Special cases: \(\phi=0\) gives \(\yb\); \(\phi=\yb/\xb\) gives the ratio estimator.

Its variance

Subtract \(\Yb\) and use \(\Xb=\Xb\): the error is

\[\hat{\bar Y}^{*}-\Yb=(\yb-\Yb)-\phi(\xb-\Xb)\]

Square and take expectation (variance of a difference):

\[\V(\hat{\bar Y}^{*})=\V(\yb)+\phi^2\V(\xb)-2\phi\,\Cv(\xb,\yb)=\frac{1-f}{n}\big[S_Y^2+\phi^2S_X^2-2\phi S_{XY}\big]\]
Question. \(S_Y=12,\ S_X=8,\ \rho=0.8,\ n=25,\ N=500\). Find the variance of \(\hat{\bar Y}^*\) for \(\phi=1\).
Solution.
\[S_{XY}=\rho S_XS_Y=0.8(8)(12)=76.8,\quad \tfrac{1-f}{n}=\tfrac{0.95}{25}=0.038\]
\[\V=0.038\,[144+1(64)-2(1)(76.8)]=0.038(54.4)=2.067\]

Compare \(\V(\yb)=0.038(144)=5.472\): already a big gain with a crude \(\phi\).

Choosing the best weight \(\phi\)

Minimise the variance

Differentiate \(\V(\hat{\bar Y}^*)\) with respect to \(\phi\) and set to zero:

\[\frac{d}{d\phi}\Big[\V(\yb)+\phi^2\V(\xb)-2\phi\Cv(\xb,\yb)\Big]=2\phi\V(\xb)-2\Cv(\xb,\yb)=0\]
\[\phi_{\rm opt}=\frac{\Cv(\xb,\yb)}{\V(\xb)}=\frac{S_{XY}}{S_X^2}=\beta\]

The second derivative is \(2\V(\xb)>0\), so this is a minimum. The best weight is the population regression slope.

The minimum variance

Use \(\beta^2S_X^2=\rho^2S_Y^2\) and \(\beta S_{XY}=\rho^2S_Y^2\):

\[V_{\min}=\tfrac{1-f}{n}\big[S_Y^2+\rho^2S_Y^2-2\rho^2S_Y^2\big]=\tfrac{1-f}{n}S_Y^2(1-\rho^2)=(1-\rho^2)\V(\yb)\]

Since \(|\rho|\le1\), this is never worse than \(\yb\). Stronger correlation, bigger gain.

Question. Same data as above. Find \(\beta\) and \(V_{\min}\).
Solution.
\[\beta=\rho\frac{S_Y}{S_X}=0.8\cdot\frac{12}{8}=1.2\]
\[V_{\min}=(1-0.64)(5.472)=0.36(5.472)=1.970\]

A 64% cut in variance relative to \(\yb\).

Estimating the slope: the regression estimator

Least squares

\(\beta\) is unknown, so fit \(y_i=b_0+b_1x_i+\varepsilon_i\) to the sample by minimising

\[S(b_0,b_1)=\sum_{i=1}^n(y_i-b_0-b_1x_i)^2\]

Setting \(\partial S/\partial b_0=0\) gives \(\sum(y_i-b_0-b_1x_i)=0\), i.e. \(b_0=\yb-b_1\xb\). Substituting into \(\partial S/\partial b_1=0\):

\[\sum(x_i-\xb)\big[(y_i-\yb)-b_1(x_i-\xb)\big]=0\ \Rightarrow\ s_{xy}-b_1s_{xx}=0\]
\[b=\frac{s_{xy}}{s_{xx}},\qquad b_0=\yb-b\,\xb\]

The estimator

Replace \(\phi\) by \(b\):

\[\Yr=\yb+b(\Xb-\xb)\]

Insert \(\yb=b_0+b\xb\):

\[\Yr=b_0+b\xb+b\Xb-b\xb=b_0+b\,\Xb\]

So it is the fitted line evaluated at the known \(\Xb\). For a total: \(\hat Y_{\rm reg(tot)}=N\,\Yr\).

Geometry. The fitted line always passes through \((\xb,\yb)\). If \(\xb<\Xb\), the sample under-represents large \(X\), so we slide up the line to \(\Xb\). The ratio estimator does the same on a line forced through the origin.

Properties: bias, wrong slopes, and ratio

Pre-assigned slope \(\beta_0\)

If \(\beta_0\) is fixed in advance (say from an earlier survey), the estimator is the difference estimator with \(\phi=\beta_0\), hence exactly unbiased. When \(b\) is estimated, a small bias of order \(1/n\) appears.

Cost of a wrong slope

From the variance formula with \(\phi=\beta_0\), expand \(\beta_0^2-2\beta_0\beta=(\beta_0-\beta)^2-\beta^2\):

\[S_Y^2+\beta_0^2S_X^2-2\beta_0\beta S_X^2=S_Y^2-\beta^2S_X^2+(\beta_0-\beta)^2S_X^2\]
\[\V\big(\Yr(\beta_0)\big)=\underbrace{\tfrac{1-f}{n}S_Y^2(1-\rho^2)}_{V_{\min}}+\tfrac{1-f}{n}S_X^2(\beta_0-\beta)^2\]

Compared with \(\yb\), the difference is \(\tfrac{1-f}{n}S_X^2\,\beta_0(\beta_0-2\beta)\), negative exactly when \(0<\beta_0<2\beta\).

Against the ratio estimator

To first order the ratio estimator is the difference estimator with \(\phi=R=\Yb/\Xb\). Putting \(\beta_0=R\):

\[\V(\hat{\bar Y}_R)\approx V_{\min}+\tfrac{1-f}{n}S_X^2(R-\beta)^2\ \ge V_{\min}\]

They tie only when \(R=\beta\): the true line has zero intercept.

Question. Data as before (\(\beta=1.2\)). For which \(\beta_0\) does the fixed-slope estimator beat \(\yb\)? Find its variance at \(\beta_0=1.5\).
Solution.
\[0<\beta_0<2\beta=2.4\]
\[\V=1.970+0.038(64)(1.5-1.2)^2=1.970+0.038(64)(0.09)=1.970+0.219=2.189\]

Still well below 5.472, but above the 1.970 of the optimal slope.

Estimating the variance and confidence intervals

Fixed slope

\[\widehat{\V}(\Yr(\beta_0))=\frac{1-f}{n}\cdot\frac{1}{n-1}\sum\big[(y_i-\yb)-\beta_0(x_i-\xb)\big]^2\]

Estimated slope (large-sample)

The residual variance estimates \(S_Y^2(1-\rho^2)\):

\[s_{y\cdot x}^2=\frac{1}{n-2}\sum(y_i-b_0-bx_i)^2=\frac{s_{yy}-b^2s_{xx}}{n-2},\qquad \widehat{\V}(\Yr)\approx\frac{1-f}{n}s_{y\cdot x}^2\]
\[\Yr\pm z_{\alpha/2}\sqrt{\widehat{\V}(\Yr)},\qquad \widehat{\V}(\hat Y_{\rm reg(tot)})=N^2\widehat{\V}(\Yr)\]

For small \(n\), use a \(t\) quantile with \(n-2\) d.f. and treat the interval as approximate.

Full worked example: store sales

\(N=200\) stores, known last-year mean \(\Xb=26\) (\$ thousand). Sample of \(n=10\):

R code
x<-c(12,18,25,31,22,40,15,28,35,20); y<-c(30,38,47,52,43,66,34,49,58,41)

c(Yreg, Yreg+c(-1,1)*qnorm(.975)*se, N*Yreg)

Efficiency against correlation

Variance relative to \(\V(\yb)\): regression gives \(1-\rho^2\); the ratio estimator (when \(C_X=C_Y\)) gives \(2-2\rho\). Slide \(\rho\).

Check: \(\rho=0.92\) gives \(1-\rho^2=0.154\), roughly an 85% variance reduction, matching the simulation of 20 000 samples (MSE 13.06 for \(\yb\) vs 2.02 for regression).

Pitfalls. Plot \(y\) vs \(x\) first; \(\Xb\) must come from the same frame; use reasonably large \(n\) (bias and normal CI are shaky for small \(n\)); several auxiliaries lead to multiple regression (GREG). The design, not the model, supplies unbiasedness to first order.

Practice

Try each problem first, then open the dropdown for the complete solution.

1. Show that \(\Yr=b_0+b\Xb\).

Given. \(\Yr=\yb+b(\Xb-\xb)\) with \(b=s_{xy}/s_{xx}\), and the least-squares intercept \(b_0=\yb-b\xb\).

Step 1. Expand the bracket.

\[\Yr=\yb+b\Xb-b\xb\]

Step 2. Group the terms that do not contain \(\Xb\).

\[\Yr=(\yb-b\xb)+b\Xb\]

Step 3. The bracket is exactly \(b_0\).

\[\Yr=b_0+b\,\Xb\]

Numerical check (store data). \(b_0=15.67\), \(b=1.2246\), \(\Xb=26\):

\[15.67+1.2246(26)=15.67+31.84=47.51\]

Same as \(45.8+1.2246(26-24.6)=47.51\). The estimator is the fitted line read at the known \(\Xb\).

2. \(S_Y=12,\ S_X=8,\ \rho=0.8,\ n=25,\ N=500\): find \(\beta\), \(\V(\yb)\), \(V_{\min}\).

Step 1: the correction factor.

\[f=\frac{25}{500}=0.05,\qquad \frac{1-f}{n}=\frac{0.95}{25}=0.038\]

Step 2: the slope.

\[\beta=\rho\frac{S_Y}{S_X}=0.8\times\frac{12}{8}=1.2\]

Step 3: variance of the sample mean.

\[\V(\yb)=0.038\times12^2=0.038\times144=5.472\]

Step 4: minimum variance of the regression estimator. Using the full bracket first:

\[S_{XY}=\rho S_XS_Y=0.8(8)(12)=76.8,\qquad \beta^2S_X^2=1.44(64)=92.16\]
\[\beta S_{XY}=1.2(76.8)=92.16,\qquad V_{\min}=0.038\,[S_Y^2+\beta^2S_X^2-2\beta S_{XY}]\]
\[V_{\min}=0.038\,[144+92.16-2(92.16)]=0.038(51.84)=1.970\]

Step 5: shortcut check.

\[V_{\min}=(1-\rho^2)\V(\yb)=0.36\times5.472=1.970\]

Standard errors: \(\sqrt{5.472}=2.34\) for \(\yb\) against \(\sqrt{1.970}=1.40\) for regression, a 64% drop in variance.

3. For which \(\beta_0\) does \(\Yr(\beta_0)\) beat \(\yb\)?

Step 1: the variance difference. Subtract \(\V(\yb)\) from the fixed-slope variance:

\[\V(\Yr(\beta_0))-\V(\yb)=\tfrac{1-f}{n}\big[\beta_0^2S_X^2-2\beta_0S_{XY}\big]\]

Step 2. Replace \(S_{XY}=\beta S_X^2\) and factor.

\[=\tfrac{1-f}{n}S_X^2\,\beta_0(\beta_0-2\beta)\]

Step 3: plug in numbers. \(\tfrac{1-f}{n}S_X^2=0.038(64)=2.432\) and \(2\beta=2.4\):

\[\text{difference}=2.432\,\beta_0(\beta_0-2.4)\]

Step 4: sign. The estimator wins when the difference is negative. The product \(\beta_0(\beta_0-2.4)\) is negative exactly between its roots:

\[0<\beta_0<2.4\]

1.22.432(1.2)(−1.2)=−3.5021.970best (\(\beta_0=\beta\))

4. The ratio estimator as a difference estimator; when do ratio and regression coincide?

Step 1: exact identity. Take \(\phi=\hat R=\yb/\xb\) in the difference estimator.

\[\yb+\frac{\yb}{\xb}(\Xb-\xb)=\yb+\frac{\yb\Xb}{\xb}-\yb=\frac{\yb\,\Xb}{\xb}=\hat{\bar Y}_R\]

Step 2: first-order variance. For large \(n\), \(\hat R\approx R=\Yb/\Xb\), so the ratio estimator behaves like \(\phi=R\) fixed. Put \(\beta_0=R\) in the wrong-slope formula:

\[\V(\hat{\bar Y}_R)\approx V_{\min}+\tfrac{1-f}{n}S_X^2(R-\beta)^2\]

Step 3: when they coincide. The extra term vanishes iff \(R=\beta\). The population line passes through \((\Xb,\Yb)\), so its intercept is \(\alpha=\Yb-\beta\Xb=\Xb(R-\beta)\). Hence

\[R=\beta\iff\alpha=0\]

Ratio and regression tie exactly when the line goes through the origin.

Numerical check (store data). \(\hat R=45.8/24.6=1.862\), \(b=1.2246\), \(s_x^2=720.4/9=80.04\), \(\tfrac{1-f}{n}=0.095\), regression variance \(0.0862\):

\[\text{extra}=0.095(80.04)(1.862-1.2246)^2=7.604(0.4060)=3.088\]
\[\V(\hat{\bar Y}_R)\approx0.0862+3.088=3.174,\quad se=\sqrt{3.174}=1.78\]

This matches the ratio se of 1.78 in the example table. Almost all of the ratio estimator's extra variance comes from the ignored intercept.

5. R simulation: compare \(\yb\), ratio and regression for \(n=10,25,50\).

Plan. (a) Build a population with a non-zero intercept. (b) For each \(n\), draw many SRSWOR samples and compute all three estimates. (c) Compute bias and MSE against the true \(\Yb\).

set.seed(2026)
Np <- 600
X <- rgamma(Np, shape = 5, scale = 6) + 5
Y <- 20 + 1.2 * X + rnorm(Np, 0, 6)      # intercept 20, not zero
Xb <- mean(X); Yb <- mean(Y)
for (n in c(10, 25, 50)) {
  est <- replicate(5000, {
    i  <- sample(Np, n); xs <- X[i]; ys <- Y[i]
    b  <- cov(xs, ys) / var(xs)
    c(srs   = mean(ys),
      ratio = mean(ys) / mean(xs) * Xb,
      reg   = mean(ys) + b * (Xb - mean(xs)))
  })
  cat("n =", n, "\n")
  print(rowMeans(est) - Yb)               # bias
  print(rowMeans((est - Yb)^2))           # MSE
}

What to expect. The lecture's run (\(n=20\)) gave MSE 13.06 for \(\yb\), 4.97 for ratio and 2.02 for regression, with theory 13.25 and 1.91. From \(\V(\yb)=\tfrac{1-f}{n}S_Y^2\) and the theory value 13.25 we get \(S_Y^2\approx274\), so the rough theoretical MSEs are:

\(n\)\(\yb\)Regression (\(\times0.144\))
10\(\approx27.0\)\(\approx3.9\)
25\(\approx10.5\)\(\approx1.5\)
50\(\approx5.0\)\(\approx0.7\)

Interpretation.

  • All MSEs shrink roughly like \(1/n\), but the ordering regression < ratio < mean stays.
  • Regression's MSE sits slightly above theory at \(n=10\), because estimating \(b\) adds a bias of order \(1/n\). The excess fades as \(n\) grows.
  • The ratio estimator's gap to regression is the \((R-\beta)^2\) term, driven by the intercept of 20.

Exact values depend on the seed and number of replications.
