Big Picture

The F test of ANOVA needs certain assumptions. The errors \(\varepsilon_{ij}\) must be normally and independently distributed with mean zero and constant (but unknown) variance \(\sigma^2\), written \(\varepsilon_{ij}\sim NID(0,\sigma^2)\). If they hold, ANOVA gives an exact test of "no difference in treatment means". We cannot see the errors, but we can see the residuals, so we study the residuals.

Residuals

The residual of observation \(j\) in treatment \(i\) is the observed value minus the fitted value:

\[ e_{ij}=y_{ij}-\hat y_{ij} \]

The fitted value is \(\hat y_{ij}=\hat\mu+\hat\tau_i=\bar y_{\cdot\cdot}+(\bar y_{i\cdot}-\bar y_{\cdot\cdot})=\bar y_{i\cdot}\). So for one-way ANOVA

\[ e_{ij}=y_{ij}-\bar y_{i\cdot} \]

that is, each residual is the deviation of an observation from its own treatment mean.

Checking Normality

Plot a histogram of the residuals. If \(NID(0,\sigma^2)\) holds, the residuals should look like a sample from a normal distribution centred at zero. A normal probability plot is also useful: if the errors are normal, the points fall approximately on a straight line.

Constructing a normal probability plot

  1. Calculate the residuals.
  2. Arrange them from smallest to largest, \(e_{(1)}\le\dots\le e_{(n)}\).
  3. Give each ordered residual a probability \(p_i=\dfrac{i-0.5}{n}\), \(i=1,\dots,n\). For \(n=20\): \(p_1=\dfrac{0.5}{20}=2.5\%\), \(p_{20}=\dfrac{19.5}{20}=97.5\%\).
  4. Plot each ordered residual against its normal probability.

Equivalently, plot the standardised normal score \(z_i\) against \(e_{(i)}\), where

\[ \frac{i-0.5}{n}=P(Z\le z_i)=\Phi(z_i)\quad\Longleftrightarrow\quad z_i=\Phi^{-1}\!\Big(\frac{i-0.5}{n}\Big) \]

For example, if \(\dfrac{i-0.5}{n}=0.05\) then \(\Phi(z_i)=0.05\), so \(z_i\approx-1.64\).

Plotting positions \(p_i\) and normal scores \(z_i\)

The \(i\)th smallest of \(n\) residuals is given the probability

\[p_i=\frac{i-0.5}{n}\]

(the 0.5 keeps \(p_i\) strictly between 0 and 1). For \(n=20\):

\[p_1=\frac{1-0.5}{20}=0.025,\qquad p_{20}=\frac{20-0.5}{20}=0.975\]

The normal score \(z_i\) is the standard normal value that has area \(p_i\) to its left:

\[\Phi(z_i)=P(Z\le z_i)=p_i\ \Rightarrow\ z_i=\Phi^{-1}(p_i)\]

Example: \(p_i=0.05\) gives \(\Phi(z_i)=0.05\), so \(z_i\approx-1.64\). For the smallest etch residual \(p_1=0.025\), so

\[z_1=\Phi^{-1}(0.025)=-1.960\]

If the residuals are normal, \(e_{(i)}\) is roughly a linear function of \(z_i\): the points lie near a straight line.

Etch rate example. The plot (drawn by the calculator below) suggests the error distribution is approximately normal. Slight curvature at both ends indicates somewhat thinner tails than a normal distribution, but the departure from normality is not substantial.

Checking Independence: Residuals vs Run Order

Plot the residuals in the time order of data collection. This detects correlation between residuals. A tendency to see runs of positive and negative residuals indicates positive correlation, which means the independence assumption may be violated.

PatternWhat it looks likeMeaning
1. Random scatter (desirable)Residuals fluctuate randomly around zero with roughly constant spreadIndependence looks reasonable; no obvious change in variance
2. Long runsSeveral positive residuals, then several negative onesPositive autocorrelation (independence violated)
3. AlternatingResiduals alternate between positive and negativeNegative autocorrelation (independence violated)
4. Upward or downward trendResiduals increase (or decrease) systematically with run orderTime-related effect, e.g. machine drift, temperature, tool wear
5. CyclicA repeating patternPeriodic source of variation, e.g. shifts, batch effects, machine cycles
6. Changing spreadSmall spread early and larger spread later (or the reverse)Non-constant variance over time

Checking Constant Variance: Residuals vs Fitted Values

This plot checks whether the behaviour of the errors changes with the predicted level of the response. We look for constant variance and model inadequacy. If the model is correct and the variance is constant, the residuals are structureless: unrelated to the fitted values, with no obvious pattern.

PatternWhat it looks likeMeaning
1. Random scatterRandomly scattered around zero, roughly constant spreadModel and constant variance assumption are reasonable
2. Increasing spread (fan)Spread grows as fitted values growNon-constant variance (heteroscedasticity)
3. Decreasing spread (reverse fan)Spread shrinks as fitted values growNon-constant variance (heteroscedasticity)
4. CurvatureResiduals form a curveModel is inadequate: missing important terms (e.g. a quadratic term or a transformation)
5. Systematic trendResiduals show a steady trendModel not appropriate (missing terms or wrong functional form)
6. Groups or clustersResiduals form distinct groupsA missing factor or an important categorical variable not in the model

Bartlett's Test for Equal Variances

Residual plots are the usual way to diagnose unequal variances, but formal tests also exist. They test whether all treatment populations have the same variance:

\[ H_0:\sigma_1^2=\sigma_2^2=\cdots=\sigma_a^2\qquad H_1:\text{the variances are not all equal} \]

Bartlett's test is widely used. For independent random samples from normal populations, the statistic is approximately chi-square with \(a-1\) degrees of freedom (\(a\) = number of treatments):

\[ \chi_0^2=2.3026\,\frac{q}{c} \]
\[ q=(N-a)\log_{10}S_p^2-\sum_{i=1}^{a}(n_i-1)\log_{10}S_i^2 \]
\[ c=1+\frac{1}{3(a-1)}\left[\sum_{i=1}^{a}\frac{1}{n_i-1}-\frac{1}{N-a}\right] \]
\[ S_p^2=\frac{\sum_{i=1}^{a}(n_i-1)S_i^2}{N-a} \]

\(S_i^2\) is the sample variance of treatment \(i\), \(n_i\) its size and \(N=\sum n_i\). Reject \(H_0\) if \(\chi_0^2\gt\chi^2_{\alpha,a-1}\).

Etch rate example. Normality is not in question, so we may use Bartlett's test. \(S_1^2=400.7,\ S_2^2=280.3,\ S_3^2=421.3,\ S_4^2=232.5\).
\(S_p^2=\dfrac{4(400.7)+4(280.3)+4(421.3)+4(232.5)}{16}=333.7\)
\(q=16\log_{10}(333.7)-4[\log_{10}400.7+\log_{10}280.3+\log_{10}421.3+\log_{10}232.5]=0.21\)
\(c=1+\dfrac{1}{3(3)}\Big(\dfrac44-\dfrac1{16}\Big)=1.10\)
\(\chi_0^2=2.3026\times\dfrac{0.21}{1.10}=0.43\)
\(\chi^2_{0.05,3}=7.81\). Since \(0.43\lt7.81\), we cannot reject \(H_0\). This agrees with the residuals vs fitted values plot.
Note: the slide says "no evidence to conclude that all four variances are not the same". Say it directly: there is no evidence that the variances differ. Not rejecting \(H_0\) does not prove the variances are equal. Also, Bartlett's test is sensitive to non-normality, so check normality first.
