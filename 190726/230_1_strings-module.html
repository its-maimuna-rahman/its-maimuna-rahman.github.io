Part 1: Concepts (with one-line examples)

1. Getting started

A string is the generic word for character-type variables. Useful for cleaning names, survey responses and labels. The stringr package (core tidyverse) provides consistent functions, most beginning with str_.

library(tidyverse)

1.1 Creating strings

Use single or double quotes; both work the same. Choose whichever makes the string easier to write.

x <- "R for Data Science"

If both quote types occur, escape the quote with a backslash \. R’s printed form shows escapes; cat() shows the text as it really appears.

cat("It's good to say, \"Welcome!\"")

1.2 Special characters

\nNew line
\tTab

cat("First line\nSecond line")

1.3 Character vectors and built-in constants

A character vector holds one or more strings.

students <- c("Anika", "Rafi", "Nusrat")

R provides letters, LETTERS, month.name, month.abb; stringr provides words, sentences, fruit.

month.abb[1:4]

3.1 Change the case

Convert to lower, upper or title case; works on vectors. str_to_title() capitalises each word and doesn’t know about acronyms or special name styles.

str_to_title("r for DATA science")

3.2 Count characters

length() gives the number of elements; str_length() gives the number of characters. A space counts as 1; an empty string is 0.

str_length("Data Science")

3.3 Substrings with str_sub()

Extract by start and end position (positions start at 1; negative positions count from the end). An end beyond the string returns what is available. Assigning to str_sub() replaces characters.

str_sub("AST230", 1, 3)

3.4 Locate a match with str_locate()

Returns the start and end positions of the first match (NA if no match).

str_locate("Welcome to the AST230 lab", "AST230")

4.1 Remove whitespace

str_trim() removes spaces at the start and end (side = "left"/"right" available). str_squish() also reduces repeated internal spaces to one. Often combined with case conversion.

str_to_title(str_squish("  anika  RAHMAN"))

4.2 Pad a string to minimum width

str_pad() adds characters until the string reaches a total width (side, pad arguments). Ideal for fixed-width IDs; it never shortens longer strings.

str_pad("7", width = 3, pad = "0")

4.3 Duplicate a string

str_dup() joins repeated copies into a single string; rep() repeats elements of a vector.

str_dup("R", 4)

5.1 Combine strings with str_c()

sep goes between arguments (element by element for vectors); collapse joins all elements of the result into one string.

str_c("AST", "230", sep = "-")
str_c(c("AST230", "AST305", "PSY206"), collapse = ", ")

5.2 Split strings with str_split()

Divides text at a separator and returns a list of character vectors (one element per input string). Use [[1]] for a single input. Splitting on "" gives individual characters.

str_split("AST_230_Lab_2026", "_")[[1]]

5.3 Extract words with word()

Extracts words by position; negative positions count from the end; a start and end give a range.

word("Institute of Applied Statistics and Data Science", -1)

6.1 Sort alphabetically

str_sort() sorts a character vector; use decreasing = TRUE for reverse order.

str_sort(c("Sylhet", "Dhaka", "Rajshahi", "Barishal"))

6.2 Comparing strings

R is case-sensitive and extra spaces matter. Clean both sides before comparing.

str_to_lower(str_trim("  DHAKA ")) == str_to_lower(str_trim("dhaka"))

7.1 Detect a match

A pattern is the text to find. str_detect() returns TRUE/FALSE per string. For case-insensitive search, convert to a common case first (note "agree" also occurs inside "disagree").

str_detect(c("AST230", "AST305", "PSY206", "CSE331"), "AST")

7.2 Match the beginning or end

^ means start of string and $ means end of string. Use both to match the whole string. These are basic regular expressions.

str_detect(c("AST230", "PSY206"), "^AST")

7.3 Count matches

Since TRUE=1 and FALSE=0, sum() and mean() give the number and proportion of matches. str_count() counts occurrences within each string. NA input gives NA; use na.rm = TRUE.

mean(str_detect(c("Dhaka", "Gazipur", "Dhaka"), "^Dhaka$"))
str_count("banana", "a")

8. Replacing text

str_replace() replaces the first match in each string; str_replace_all() replaces every match. The original is unchanged unless you assign the result.

str_replace_all("banana", "a", "-")

9. Working with character columns

stringr functions are vectorised, so they work naturally inside mutate() and, with str_detect(), inside filter().

students |> mutate(name = str_to_title(str_squish(name)))
students_clean |> filter(str_detect(course, "^AST230$"))
